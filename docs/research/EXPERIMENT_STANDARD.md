# Experiment Standard

Every experiment record should include:

- experiment_id
- research_question
- hypothesis
- dataset_id
- dataset_version
- task_type
- split_strategy
- random_seed
- preprocessing
- views
- representations
- blocking_method
- matching_or_clustering_method
- hyperparameters
- evaluation_metrics
- comparison_baselines
- code_commit
- environment
- output_location
- validation_status
