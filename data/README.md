# Data

- Raw data are immutable and should not be modified in place.
- External-data provenance and licensing should be documented in docs/datasets/DATASET_CATALOG.md.
- Reference labels and mappings are treated as reference assets rather than experimental results.
- Files under data/ are not automatically included in Git; large or sensitive datasets should be managed carefully.
- Licensing constraints must be respected when adding new local copies of external datasets.
